# 3D虚拟服装试穿销售平台
## 项目简介
本项目为**基于3D技术的虚拟服装销售平台**，隶属于“互联网+”大学生创新创业大赛社会服务类项目。

针对传统线上服装网购**无法实景试穿、版型展示单一、尺码匹配难、退换货率高**等行业痛点，依托 Web3D 与三维仿真技术，打造沉浸式虚拟试衣系统。用户可在网页端操控3D虚拟人像，实现**360°全景查看、一键换装、缩放视角**等功能，还原线下试衣体验，重构服装新零售模式。

平台采用**线上3D虚拟商城 + 线下概念体验店**的O2O商业模式，面向15-35岁年轻消费群体，兼具实用性、趣味性与科技感。项目不仅优化消费者购物体验，同时助力传统服装商户数字化转型，还可创造线上运营、网络营销等就业岗位，具备商业价值与社会价值。

## 核心功能
1. 3D虚拟人物展示，支持鼠标拖拽**360°旋转**、滚轮缩放视角
2. 多款式服装一键切换试穿，实时预览穿搭效果
3. 界面简洁友好，无需额外安装软件，浏览器直接访问使用

## 技术栈
- 前端：HTML + CSS + JavaScript
- 3D图形引擎：Three.js
- 部署方式：GitHub Pages 静态网站部署

## 使用说明
1. 鼠标左键拖动画面：旋转3D人物，多角度查看服饰
2. 鼠标滚轮：放大/缩小视图
3. 点击右侧功能按钮：切换不同款式服装、还原默认样式
