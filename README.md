# 3D虚拟服装试穿销售平台
## 项目简介
本项目为**基于3D技术的虚拟服装销售平台**，隶属于“互联网+”大学生创新创业大赛社会服务类项目。

针对传统线上服装网购**无法实景试穿、版型展示单一、尺码匹配难、退换货率高**等行业痛点，依托 Web3D 与三维仿真技术，打造沉浸式虚拟试衣商城系统。
平台采用**线上3D虚拟商城 + 线下概念体验店**的O2O商业模式，面向15-35岁年轻消费群体，兼具科技展示性与商业落地性。
项目可帮助传统服装商家数字化转型，同时创造线上运营、新媒体营销等就业岗位，兼具商业价值与社会价值。

## 核心拓展功能
### 一、3D交互模块
1. 3D虚拟人像实时渲染，支持鼠标拖拽360°全方位旋转模特
2. 鼠标滚轮缩放画面，近距离查看服装版型细节
3. 一键切换多款服饰，实时预览上身穿搭效果
4. 加载动画提示，解决3D资源加载空白体验问题

### 二、线上商城销售模块
1. 商品列表+标价展示，三款主流女装定价清晰
2. 购物车计数系统，试穿满意可一键加入购物车
3. 弹窗加购提示，模拟真实电商下单流程

### 三、适配优化
1. PC端完整大屏展示，适合大赛答辩现场演示
2. 移动端自适应布局，手机、平板均可流畅访问
3. 国内稳定CDN资源，大幅降低海外脚本加载失败、画布空白问题

## 技术栈
- 页面布局：HTML5 + CSS3 响应式样式
- 页面交互：原生JavaScript
- 3D图形渲染引擎：Three.js r132
- 线上部署：GitHub Pages 静态网站免费托管

## 操作使用指南
1. 打开上方演示链接，等待3D模型加载完成
2. 鼠标左键拖拽3D画布：旋转模特多角度看衣服
3. 鼠标滚轮上下滑动：放大/缩小模特画面
4. 右侧点击商品按钮：一键试穿对应服装
5. 试穿满意后点击「加入购物车」，模拟电商下单流程
